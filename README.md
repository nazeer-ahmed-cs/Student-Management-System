# Student Management System

A comprehensive Student Management System for managing student records, courses, and academic performance.

## Features

- **Student Records**: Add, update, delete, and view student information
- **Course Management**: Manage courses and enrollments
- **Grade Tracking**: Record and calculate student grades
- **Search Functionality**: Quick search by student ID, name, or course
- **Reports**: Generate student performance summaries

## Technologies Used

- **Language**: C++ / Java
- **Concepts**: Object-Oriented Programming, Data Structures
- **Data Storage**: File-based system

## Getting Started

### Prerequisites

- C++ or Java compiler
- Any code editor or IDE

### Running

1. Clone the repository
2. Extract the source files
3. Compile and run
